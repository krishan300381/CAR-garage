This professional README.md is designed for your Automotive Inventory Tool (Car Garage System). It highlights your fundamental programming skills in C and your ability to manage data persistence without a database, which is a key technical indicator for freshers.Automotive Inventory Management System (CLI)A console-based inventory tracking application developed in C to manage vehicle sales, repurchases, and stock status. This project demonstrates the application of structured programming and manual data persistence through file handling protocols.🛠️ Key FeaturesInventory Tracking: Comprehensive tool for logging car sales and repurchases with real-time status updates.File-Based Persistence: Engineered custom file handling logic to maintain a persistent database of 100+ car entries without an external DBMS.Search & Sort Algorithms: Implemented custom algorithms to retrieve and organize inventory data with $O(n)$ time complexity.Data Integrity: Utilized structured C programming to ensure record integrity during read/write operations to local storage.💻 Tech StackLanguage: C.Storage: File Handling (Standard I/O).Methodology: Structured Programming.🧩 Technical LogicThe system is built on a modular logic structure:Data Structure: Uses a struct to define vehicle attributes including Sale ID, Model, and Purchase Status.Persistence Layer: Employs fopen, fwrite, and fread to manage the lifecycle of data in a .txt or .dat format.Validation: Includes basic input validation to prevent record corruption during the inventory update cycle.🚀 Setup and ExecutionClone the Repository:Bashgit clone https://github.com/krishan300381/CAR-garage.git
